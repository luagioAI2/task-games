## 加载页第四版（2026-10-27 收尾）

上一轮把源码改了、包也打了（21:21）、图也截了，但**没提交、没装进宿主、没跑 e2e**，
而且 `manifest.version` 还是 `1.0.0` —— 宿主只比 `installed.version === g.version`，
不升版本的话界面会说「已是最新」，用户装到的还是第三版的暗画面，**零报错**。

三处改动：

1. **删掉标题上方那行小字**（`boot.brand`：深渊矿业公司 / Abyss Mining Co. / 深淵鉱業）。
   三语都删了，`.ld-brand` 样式一并删；标题字号从 `clamp(25px,7.2vw,33px)` 提到 `clamp(28px,8vw,37px)`。
2. **整体从「暗」改「暖」**：井筒 `#463A63→#140F20` 改成 `#FFFDF7→#F3C589`，岩体换成暖陶土色，
   井底那团光从 `ldAbyss` 改名 `ldHaze`（同时避开和宿主 `@keyframes` 撞名的风险）。
   原因写在源码注释里：用户反馈「太阴暗了」。矿井题材容易顺手画成夜景，但这是给小孩玩的。
3. ★ **平板裁切**：`.ld-art` 的 `max-width: 470px` 改成 `min(100%, 640px)`。
   真因不是「470 太小」而是 **flex 项只要有一侧 `margin: auto` 就不做拉伸**，
   宽度退化成「内容固有宽度」= 高度 × viewBox 比例（320/460）。
   平板竖屏高 898 ⇒ 天然宽 625，被硬夹到 470 ⇒ 左右各裁约 40 个 viewBox 单位，
   贴边放的金块被切掉半个。判据是**看截图**（`shots/_loading/t47.png` 两侧金块完整）。

### 顺手补的工具：`scripts/install-to-host.mjs`

之前这款是**手工**拷包 + 手改 `index.json` + 手跑 `make-local-catalog`。
后果已经发生过一次：工作区里躺着一个「重打过但提交时 `git add` 漏掉」的包，
清单记下的是**那个没入库的构建**的哈希（1170500），而 HEAD 里是 1168546
⇒ 清单成孤儿、`check:registry` 报「换了包没重算哈希」，而 `git status` 是干净的。

现在一次运行做完三件事（拷包 / 改清单 / 重算哈希），`--check` 只比对不写。

★ `--check` 比的是 **`Buffer.equals`**，不是字节数 —— 这次就撞上了：
`1.0.0` → `1.0.1` 长度相同、注释又被剥掉，**新旧包都是 1170500 字节**，
只比大小会得出「没变」的结论。反向验证过：装之前 `--check` 报两条（不是同一份 / 版本不符），装完 exit 0。

## 尺寸决定：**不重新压图**（2026-10-26）

`assets/` 一共 13.3 MB / 190 个文件（精灵 7.89 MB / 156 个、音频 3.33 MB、环境 2.04 MB）。
和已经上架的几款比：

| 游戏 | 资源体积 |
| --- | --- |
| 云边小农场 | ~15 MB |
| 少女战记 | ~14 MB |

| 爆汁瓜瓜罐 | 8.6 MB |

它**不是最大的那一档**，而且原站已经把图做成 webp。本机没有 `ffmpeg`，190 张 webp 重编码
要另装编码器 —— 收益（最多省几 MB）不抵风险（`im.save()` 中途被杀会截断成 0 字节，
下一轮直接 `UnidentifiedImageError`，见记忆里的原子写规则）。所以**跳过**这一步，
也就没有「压完重看截图」这道检查（精灵缩放用的是**实际纹理宽**，见 `artScale`）。

## 这次踩到并修掉的

1. **升级按钮的价格没带 `$`**（`src/ui.js` 两处：建按钮 + 每 0.2 秒覆盖的那次）。
   截图里是「持有 $1.00M」旁边挂一个「7.86」。两处都要改 —— 只改建按钮那次，
   0.2 秒后就被覆盖回去了（第一次改完重拍，图上还是 7.86）。
2. **语言混排**：`mountDom()` 里先填了一遍文案（模块默认日语），`setLang()` 在之后才跑
   ⇒ 静态标签是日文、动态是中文。`start()` 里 `setLang` 之后**再填一次**。
3. **`onLang` 没有退订**：每次挂载都留一个闭包，持有上一次（已置空）的 `game`
   ⇒ 第二次挂载报 `Cannot read properties of null (reading 'ui')`。改成返回 unsubscribe。
4. **`document.body` 提示是误报**：`check-plugin` 报「包里引用了 document.body」，
   实际来自内联的 **pixi**（`_hookDiv` 的移动端触摸钩子），不是我们的代码。
5. **`check-plugin` 的「样式必须收进根选择器」原来只能靠人工**。这次把它做成了**打包期审计**
   （`build-plugin.mjs` 第 ② 步）：`buildCss()` 的输出逐条扫，每条选择器都必须以
   `#mng-root` 开头。判据 408 条规则 / 0 漏网 / 22 个 keyframes 都带 `mng-` /
   0 处 `url(assets/…)` 没换绝对地址。**反向验证**：同一段扫描跑未作用域化的原样式表
   ⇒ 415 条漏网，所以它不是恒真。
6. **加载页重做（第三版才成立）**。第一版整屏青海波 + 三色渐变方框 + 小吊篮；
   第二版换成矿道剖面，但截图一看还是难看。真正的原因是三条**画法**错误，不是配色：
   - **岩体画成「等高的横向色带 + 每条带顶上一条亮边」** —— 那是画木板的画法，
     整片岩壁读成瓦楞纸。改成「竖向渐变压暗 + 几块不规则大色斑 + 锯齿边 + 边缘暖光」。
     中间试过「斜向节理线」（读成铅笔划痕）和「整块压暗成剪影」（丢了和纸调子），都不行。
   - **吊笼只有顶梁和底板、没有竖栏** ⇒ 读成一张长凳。补四根竖栏 + 笼底矿石堆。
   - **金粒是浮在岩面上的孤立菱形** ⇒ 像撒了把彩纸；改成一道金色折线 ⇒ 像一支黄箭头。
     最后是「稍大的暗色窝 + 坐在窝里的金块 + 一点点光晕」才读成矿脉。
7. **模板字符串里写注释打了一个反引号**（`dom.js` 整页 HTML 是反引号模板，注释里给
   `slice` 加了反引号）⇒ 模板在 165 行提前闭合，后面的标签变成 JS 表达式。
   **`node --check` 照样通过**（尾部落到合法语法上），症状是加载页只剩上半截、
   `#boot-error` 整个没了 —— 完全静默。现在 `mount-test.mjs` 有一条
   「加载页结构完整（模板没被截断）」查模板**末尾**的节点在不在。
8. **横屏平板上 0% 的加载页是一条空井**。剖面用 `slice` 铺满，盒子比 viewBox 更宽时
   会按宽度放大、上下各裁一截；`xMidYMax` 把裁切全压在顶上，正好把吊笼起点裁没。
   改成 `xMidYMid` + 吊笼起点从 30 抬到 56。判据是量出来而不是看出来的：
   `scripts/capture-loading.mjs` 在手机竖 / 平板竖 / 平板横三档量「吊笼在不在框里」。
9. **量几何时两个坑**（都是「读数不可信」而不是「代码坏了」）：
   ① `transition` 没跑完就取样 ⇒ p=1 读出来是 p=0 的位置，看着像 `--p` 没生效；
   ② App 还在加载时 `setLoading()` 每帧覆盖 `--p` ⇒ 手设的值立刻被改回去（量到进度条 90%）。
   探针现在先 `transition:none`，再塞哨兵值轮询到「没人再写 `--p`」才开始量。

## 环境坑

- **`mkplay.zone` 直连 000**，必须 `--proxy http://127.0.0.1:7897`；沙箱自带的 `HTTP_PROXY`（62xxx）对这个站 exit 56。
- Node 22 的 `fetch` 不读 `HTTPS_PROXY`；且 `fetch` 与 `ProxyAgent` **必须从同一个包取**
  （宿主 `node_modules/undici` v8 vs Node 内置 v6，混用报 `invalid onRequestStart method`，
  症状是 `fetch failed`，看着像站点挂了）。
- 常用端口 4180/4190/4391 常年被别的项目占着；起服务后先验「服务的到底是不是我的构建」。
- `node /tmp/x.mjs` 会被解析成 `E:\tmp\x.mjs`（MSYS 不转换）⇒ 临时脚本写在仓库里再删。
- `npx vite preview ... &` 在非交互 shell 里活不过那一次工具调用 ⇒ 要 `run_in_background`。
